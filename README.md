gi# Tech.Care - Healthcare Dashboard

## Project Description
Tech.Care is a modern, responsive healthcare dashboard web application designed to provide an overview of patient information, diagnosis history, vital signs, and lab results. The dashboard offers an intuitive interface for healthcare professionals to monitor and manage patient data efficiently.

## Features
- Patient list with search functionality
- Detailed patient profile including personal information and emergency contacts
- Diagnosis history with blood pressure charts visualized using Chart.js
- Vital signs display including respiratory rate, temperature, and heart rate with status indicators
- Diagnostic list with problem descriptions and status badges
- Lab results section with downloadable reports
- Responsive and clean UI styled with CSS variables and FontAwesome icons

## Technologies Used
- HTML5 and CSS3 for structure and styling
- JavaScript for dynamic content and API integration
- [Chart.js](https://www.chartjs.org/) for interactive charts
- [FontAwesome](https://fontawesome.com/) for icons
